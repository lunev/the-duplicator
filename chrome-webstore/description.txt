Duplicate the current Chrome tab and instantly add a custom URL parameter — the fastest way to test admin flags, environment overrides, tracking params, or any query string you use every day.

FEATURES
• Duplicate with parameters — append a saved parameter or path to the current tab's URL in one click, either opening a new tab or updating the current one.
• Basic and Advanced modes — Basic mode for quick one-off duplication, Advanced mode to manage a full list of reusable parameters.
• Unlimited saved parameters — save as many URL parameters or paths as you need.
• Parameter groups — organize saved parameters into groups and filter the list down to just one group at a time.
• Drag-to-reorder — reorder your saved parameters by dragging, since list order controls which number key (1-9) triggers each one.
• Keyboard shortcuts — open the extension and fire a saved parameter without touching the mouse: Ctrl/Cmd+Shift+L, then a number key (1-9).
• Side panel support — pin the extension to Chrome's side panel for a persistent view alongside your tabs, or use the classic popup.
• Copy to clipboard — copy any saved parameter with one click.
• Export/import — back up your parameter list or move it to another machine as a JSON file.

HOW TO USE
1. Click the extension icon in the toolbar, or press Ctrl/Cmd+Shift+L.
2. Type a URL parameter or path (for example: admin, or ?debug=true) and press Enter to save it.
3. Click a saved parameter to open a duplicate tab with it appended, or press Ctrl/Cmd+Shift+L then a number key (1-9) for instant recall.
4. Drag a parameter's handle to reorder the list and change its shortcut number. Switch to Advanced mode to organize parameters into groups, or export/import your list as JSON.

PRIVACY
This extension does not collect any personal data and makes no network requests of any kind. Your saved URL parameters, groups, and preferences are stored locally via Chrome's storage API, and sync across your own signed-in Chrome browsers the same way your bookmarks do. Nothing is ever sent to the developer or any third party.

PERMISSIONS
• "storage" — saves your URL parameters, groups, and preferences so they persist between sessions.
• "activeTab" — reads the current tab's URL only when you click the icon or use the keyboard shortcut, to build the duplicated tab's URL. No other open tabs are ever read.
• "sidePanel" — enables the optional side panel view.
